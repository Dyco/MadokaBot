# MadokaBot

**樋口円香主题 QQ 机器人** · 基于 NoneBot2 与 OneBot V11

提供每日签到、运势、积分商店、角色聊天，以及链接解析、RSS 订阅、Steam 状态播报和 CS 赛事查询等功能。

当前版本：0.4.1

[基础功能](#基础功能) · [商店内容](#商店内容) · [扩展功能](#扩展功能) · [群管理](#群管理) · [参考项目](#参考项目)

## 基础功能

| 功能 | 内容 | 常用入口 |

### 使用规则

- **运势**：每日运势
- **许愿**：许愿池内容
- **每日记录**：运势、许愿及投胎的次数记录，群聊、私聊与不同群之间共享对应记录。
- **积分往来**：转账与赠礼双方均须注册；转账数量为正整数。赠礼按商店价格扣款，商品进入对方库存后由对方切换使用。
- **积分红包**：人数超过20时自动按20人发放，总积分保持不变且不能少于实际人数。每人限领一次，领取后播报所得积分和剩余个数。抢完或1小时到期后按领取积分从高到低发送汇总，到期退回剩余积分。

## 商店内容

商店提供**角色立绘**与**签到模板**。默认签到模板免费发放，其余模板使用积分购买，购买后可切换用于签到及资料卡片。

签到模板包含 Persona3、Persona5、尼尔档案、明日方舟、海报艺术、装饰艺术、斯普拉遁与蔚蓝档案等风格

通过 `/商店 立绘`、`/商店 签到模板` 浏览商品，或使用 `/查询 签到模板` 查看已拥有的模板。

## 扩展功能

### 每日投胎

模拟现实、异世界、二次元或二游投胎，生成出生地地图、人生属性、异世界出生档案或作品身份卡片。

| 模式 | 免费投胎 / 查看当天结果 | 积分重开 |
| --- | --- | --- |
| 世界 | `/投胎`、`/reborn` | `/投胎 重开` |
| 中国 | `/投胎中国`、`/rebornCN` | `/投胎中国 重开` |
| 日本 | `/投胎日本`、`/rebornJP` | `/投胎日本 重开` |
| 美国 | `/投胎美国`、`/rebornUS` | `/投胎美国 重开` |
| 异世界 | `/投胎异世界`、`/rebornIsekai` | `/投胎异世界 重开` |
| 二次元 | `/投胎二次元`、`/投胎动漫`、`/rebornAnime` | `/投胎二次元 重开`（别名同样支持） |
| 二游 | `/投胎二游`、`/rebornGames` | `/投胎二游 重开` |
| 全部 | `/一键投胎`、`/rebornAll` | `/一键投胎 重开` |

- 七种模式各自每天免费一次，无需注册；重复调用查看当天结果。四类异世界共用异世界模式的每日机会，所有二次元作品共用二次元模式的每日机会，七款二游共用二游模式的每日机会。指令起始符遵循全局 `COMMAND_START`，表中以 `/` 为例。
- 已注册且已领取对应模式当天结果后，每次花费一定积分可以重开，不限次数。
- 二次元现有 21 部作品，按预设使用日常、异世界或战斗档案，部分作品开启多人婚育；作品列表与危险度见[二次元资料说明](assets/json/daily_reborn/anime/README.md)。
- 二游现有 7 款游戏，展示人气、战力、觉醒次数、战斗属性及模拟卡池表现，综合评级遵循各游戏最高稀有度；详见[二游资料说明](assets/json/daily_reborn/games/README.md)。



### 链接解析

直接在群聊发送分享链接即可自动解析，支持视频、图片和音乐内容；`/解析` 仅用于管理设置。

**支持平台**：Bilibili、抖音、TikTok、AcFun、X、微博、小红书、YouTube、网易云音乐、酷狗音乐。

使用 `/解析 查看` 查看当前设置，或通过 `/解析 打开 B站`、`/解析 关闭 视频` 等指令按平台和内容类型控制解析。

### RSS 订阅

支持 RSS / RSSHub 动态订阅、定时更新推送、图片处理与内容去重；可结合 aria2 下载种子或磁力资源并上传群文件，支持文件选择、任务终止、重试与记录查询。

常用入口：`/RSS 添加 <名称> <RSS地址>`、`/RSS 查看全部`、`/RSS 帮助`。也可使用 `/订阅` 作为主命令别名。

### Steam 状态

绑定 Steam 账号，查看群内玩家资料、绑定情况与在线状态，推送游戏上线和离线消息；支持在当前群隐藏个人推送及设置昵称备注。

常用入口：`/steam bind <SteamID或好友码>`、`/steam check`、`/steam help`。管理员可使用 `/steam enable` 或 `/steam disable` 控制群播报。

### CS 赛事与战绩

查询 HLTV 赛事与比赛数据，生成 Rating 3.0 统计卡片，订阅比赛结果与开赛提醒，参与积分竞猜；支持绑定并查询 5E、完美平台玩家战绩。

常用入口：`/cs event`、`/cs sub <赛事ID>`、`/cs 战绩 5E <玩家昵称>`、`/cs help`。

### 模板制图

接收图片并按音乐主题模板生成图片，可指定模板、标题与子标题。

用法：`/制图 音乐 <图片> [模板] [标题] [子标题]`。

### 音游查分（RhythmGame_OCM）

通过 LXNS 查询舞萌 DX 与中二节奏的玩家资料、指定谱面最佳成绩，并生成 B50 图片，支持群聊与私聊。
支持按需补齐角色、地图头像和名牌版，超级用户使用 `/chu update` 更新曲绘与曲目数据。

## 群管理

- 管理群白名单与黑名单，控制群内功能访问。
- 仅自动同意白名单中且不在黑名单中的群邀请，其余邀请由人工处理。
- 加入非白名单群时发送提示；群人数超出设定范围时，提示并在 3 分钟后复核退群，期间加入白名单或人数恢复正常可取消退群。

管理入口：`/群白名单 添加 <群号>`、`/群白名单 列表`、`/群黑名单 添加 <群号>`。
