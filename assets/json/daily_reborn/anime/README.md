## 世界危险度

| danger | 题材标准 | 额外风险基础概率 |
| --- | --- | --- |
| 安全 | 极其安全、没有危险情节的作品 | 0% |
| 和平 | 现代日常社会，仍可能存在案件或偶发危险 | 3% |
| 动荡 | 不稳定因素较多 | 14% |
| 危险 | 咒术回战、火影忍者、死神或一般冒险异世界 | 30% |
| 灾难 | 进击的巨人、末世、丧尸或灾难密集的世界 | 50% |

分类和危险度是作者预设的玩法判断，不自动按角色评级推导，也不是原作官方风险分级。额外风险乘以 `1 + (3 - 运气) × 0.12` 与 `1 - 战力比例 × 0.45`；炮灰再乘 1.35，主角乘 0.7。额外风险触发后寿命缩短至原预期的 75% 以内，并在本作品的死因和大事件中按权重选取。基础寿命及其健康、家境、运气浮动沿用现实人生算法；阵营可为灵体等配置自己的寿命范围。安全作品禁止配置危险事件，但仍可存在基础健康因素造成的短寿。

事件可限制适用阵营与年龄，避免跨作品或不适合身份的事件。概率、匿名角色在某事件中遇难的结果属于玩法，来源只支持事件或设定本身。咒灵、虚、鬼使用专属死因和自然终结描述，不套人类的疾病；这些阵营关闭婚育。

## 存在感、婚育与评分

存在感包括路人、配角、炮灰、工具人、反派、大反派、主角。日常番排除反派和大反派；`antagonist: true` 的敌对阵营仅抽反派或大反派。其余按基础权重 42、18、15、10、9、5、1 抽取，魅力提高配角和主角的相对概率。存在感描述叙事定位，不保证存活或最高实力。

成年且活到结婚年龄才可能结婚生育。`harem: false` 使用单配偶结果，如“结婚 - 3名子女”；`harem: true` 允许一至四位配偶，示例“结婚（三人） - 共5名子女”。配偶人数不含本人，子女数为总数，并受存活的成年年数限制。`marriage: false` 的阵营不会生成婚育。当前六部开启多人婚育：To LOVE、约会大作战、契约之吻、地下城、不正经的魔术讲师、High School DxD；这是用户确认的玩法设置，不代表原作婚姻结局。

日常番和异世界番的五项属性沿用联合星级分布及家境保障的抽样，再按题材对应命名；可见魅力与婚育所用魅力一致。每项 1～5 星（半星一档）依次贡献 2、4、7、10、13、16、18、19、20 分，五项相加。全五星 100，全四星半 95，全四星 90。

战斗番在阵营内抽取评级及对应的模拟战力，高天赋提高高战力档位的相对权重。D、D+、C、C+、B、B+、A、A+、S 对应 2、4、7、10、13、16、18、19、20 个玩法分值；总分为“天赋分值 + 人气分值 + 战力分值”乘 5/3 后取整。字母战力和总分用于卡片玩法，不是跨作品强弱比较，也不把军衔、猎人功绩等同于原作战斗力。

咒术回战的“准特级咒术师”“准特级咒灵”按用户要求保留为玩法扩展，不称为原作正式等级。部分作品没有统一评级时，使用资料中的身份、资格或明确的描述性成长标签；相关说明保留在作品 `notes` 中。

## 精简格式

`manifest.json` 保留结构版本、资料版本、标题、玩法说明、性别池和作品文件清单。`sources.json` 只登记仍使用的来源 ID、标题、URL、类型、发布方及核对日期。

每部作品的必填字段：

| 字段 | 含义 |
| --- | --- |
| `id`, `title`, `weight` | 稳定作品标识、标题、抽取权重 |
| `category`, `danger` | 上表所列三类之一、五档危险度之一；新增作品必须预设 |
| `logo` | `image/reborn/` 下的标题图文件名 |
| `harem` | 是否允许多配偶人生结果 |
| `source_refs` | 本作品实际使用的来源 ID |
| `death_causes` | 适配题材的风险死因候选，通用衰老与疾病分支由算法处理 |
| `events` | 本作品大事件列表，无事件时填空数组 |
| `factions` | 战斗番必填的阵营池，非战斗番可省略 |

事件由 `name`, `weight` 及可选 `factions`（阵营 ID 数组）、`age`（含端点的适用年龄范围）构成。通用奇幻异世界死因可配置瘟疫、疾病、意外、探险事故、作战、魔物袭击、遗迹陷阱、决斗、魔法失控、诅咒、饥荒、自然灾害等；请按具体作品删减，不能整表盲用。寿终正寝由自然分支提供。

战斗阵营保留 `id`, `name`, `weight`，评级放在 `ranks` 中，每项为 `[显示评级, 权重, 模拟战力]`。多个阵营共用评级时将 `ranks` 放到作品根节点，特殊阵营可单独覆盖，避免重复维护。阵营还可使用 `antagonist`, `marriage`, `lifespan`, `natural_death`, `death_causes` 覆盖其叙事定位与人生设置。

最小日常作品示意（需先准备标题图和真实来源，不直接加入运行名单）：

```json
{
  "id": "example_daily",
  "title": "示例校园作品",
  "weight": 1,
  "category": "daily",
  "danger": "安全",
  "logo": "example_daily.png",
  "harem": false,
  "source_refs": ["example_official"],
  "death_causes": ["疾病", "意外"],
  "events": []
}
```

新增异世界作品使用 `category: "isekai"`，其余必填字段相同；按该作品设定配置危险度、后宫标记、死因和事件。新增战斗作品还需填写阵营评级。所有 JSON 经原有资源入口与 core `JsonDataStore` 读取，更新版本后重启生效，不执行 JSON 表达式或脚本。

本版删除了旧 `sections`, `history_fields`, 大量隐藏路线、术式、装备、地区、重复选项说明及逐条重复引用，只保留当前卡片与抽取使用的字段。已保存的旧版结果按其原有快照展示，不迁移或重抽；新抽取使用 `anime_v2`。历史保留旧评级文字并可与新分数记录共存。`pool-review.md`、`validation.md` 仅为旧版本历史文档。
