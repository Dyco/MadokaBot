# 二次元小范围字段与低阶段整理

核对日期：2026-10-19。资料版本：`2026.10.19.3`。本轮范围为 `/投胎二次元` 的八个世界，不包含异世界、二游模式。

## 判断口径

同时检查字段的总条目数与每次满足前置条件后的实际候选数。总数不超过四项，或任一可达条件下只剩一至四项，均进入下表。范围为 70 个字段池；共 39 个池总条目不超过四项，66 个池至少有一种条件下候选不超过四项。共用性别池仅男、女两项，它不是等级字段，保持不变。

依赖字段只剩一项通常是为了保持设定关联，例如国家跟随忍村、装备跟随职业；不应将这些关联当成四选一以上的独立抽奖。新增学习阶段明确写作阶段或身份，不冒充原作新增军衔；补完后仍不足五项的继续记录，不凑数。
