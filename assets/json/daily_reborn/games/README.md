综合评级是插件对匿名角色的模拟评价。原神等游戏的低星、字母游戏的 D/C/B 档及原作未实装的低档组合属于玩法扩展；最高档按游戏预设，不产生六星原神或 SS 级异环。等级沿用已收录的常规养成模板，不含特殊突破、圣杯等上限扩展。方舟的0次潜能提升对应潜能1，FGO的0次宝具强化对应宝具等级1；两者的次数不会直接冒充原作等级。

## 联动规则

- 人气和战力各自沿用公共的 1～5 星、半星一档分布。
- 养成次数从0开始抽取，次数 `n` 的相对权重为 `0.6ⁿ`，越高越少见；每格星星代表一次实际提升，允许全部为空。
- 人气和战力各贡献45%的综合质量，养成进度贡献10%。两项星级按 `(星级 - 1) / 4` 归一化，养成按 `次数 / 上限` 归一化；相加后按游戏的评级档数等距分档。评级最高档用金色，其余逐档区分色彩。
- 先在该评级可用的等级上限中选取已解锁档位，再抽取当前等级。方舟精英化后从1级重新计算，其他游戏使用相邻突破档位区间。方舟与FGO按评级覆盖等级模板，避免低星抽到高星专属上限。
- “抽取玩家”表示持有该匿名角色的玩家人数。人气越高，潜在持有人数区间越高；相同人气下，评级越高，持有率越低。具体人数仍有随机浮动，不是实际游戏统计。
- 卡池收入由持有人数乘以模拟单人投入生成；综合质量与养成进度提高投入，保留随机波动。金额范围为1万元至不足100亿元，只显示万元级、十万元级、百万元级、千万元级、亿元级、十亿级，不是真实流水估算。

## 精简字段

`manifest.json` 仅保存结构版本、资料版本、标题、玩法说明、性别池及游戏文件清单。每款游戏保留：

| 字段 | 用途 |
| --- | --- |
| `id`, `title`, `weight`, `logo` | 稳定标识、游戏名、抽取权重和标题图文件名 |
| `regions` | 可抽取的地区文本列表 |
| `combat_attributes` | 元素、系谱、职业或职阶文本列表 |
| `awakening` | 该游戏的次数名称 `label` 与提升次数上限 `max` |
| `rarities` | 从最低至最高排列的综合评级文本，不混用其他游戏评级 |
| `level_caps` | 必填的 `default` 等级上限序列，以及可选的评级专用序列 |
| `source_refs` | 实际使用的来源 ID，来源清单只保留简要登记 |
| `notes` | 必要的原作与玩法口径说明，可省略 |

已移除旧 `pools`、`sections`、`history_fields`、重复的逐条引用，以及不再展示的组织、种族、武器、技能、信赖、牵绊等字段。资料经既有资源入口与核心 `JsonDataStore` 读取，不执行 JSON 中的表达式或脚本。

新抽取保存为 `games_v2`，记录只保留展示所需的结果。当前格式快照继续展示；更早版本不再兼容，只提示重开或次日领取。历史缺少展示字段时直接跳过，不迁移或删除玩家记录。
