# 异世界投胎数据包

当前版本：2026.10.19-v4，结构版本：2。四个标题仍由世界JSON中的title决定：奇幻世界、赛博未来、仙侠修仙、诡秘之主。

运行资料统一位于 assets_path/json/daily_reborn/isekai，经公共资源管理器定位，再由核心 JsonDataStore 读取。修改后重启机器人刷新缓存；内容更新同时修改 manifest.json 的version。既有结果保留原快照，不重新生成父母或出生条件，不修改数据库表名、积分和每日次数规则。

## 文件职责

- manifest.json：总标题、版本、世界清单、性别游戏权重与source_catalog。
- fantasy.json、cyberpunk.json、cultivation.json、mysteries.json：实际参与生成的四类世界。
- sources.json：当前来源目录，含访问程度、支持内容和限制；运行条目通过source_refs引用。
- expansion_backlog.json：待核验与排除清单，不参与抽取。
- revision.json：第三版逐项修订范围、数量和上一轮14项问题的处理状态。
- power_range_review.json：第四版实力小池检查、161个身份的修订前后范围及不能继续下调的原因，不参与抽取。
- verification.json：第二版的历史核验快照，不覆盖为第三版结果，也不参与抽取。

[网络核验报告](../../../../madokabot/plugins/daily_reborn/research/isekai/verification_2026-10-19.md)保留发现问题时的证据与访问限制；[第三版修订说明](../../../../madokabot/plugins/daily_reborn/research/isekai/revision_v3.md)解释基础模型的处理结果，最新范围见[较低实力等级与剩余小池](../../../../madokabot/plugins/daily_reborn/research/isekai/lower_power_ranges.md)。

## 第三版修正

奇幻沿用D&D 2024基础规则范围，补充9物种的生理背景和大致寿元、24祖源的依据、家庭启蒙环境。物种背景不等于新生儿已经拥有职业等级、施法训练或成人能力；寿元不是本次出生的必然寿数。阿斯莫和奇械师不因属于其他D&D资料就自动并入当前SRD范围。

赛博明确采用原创未来，参考RED的家庭结构和现实技术维度，不声称复刻2045或2077正史。医疗照护、身份登记和信息接入分开抽取；轨道地区只选择轨道医务站，地表不抽轨道照护。公共执法身份移出企业专业家庭，另设公共服务家庭。岗位技能不是RED的Role Ability，父母权限和义体不自动遗传。

修仙补充8类灵根档案：未辨明、暂未检出、四/五属性伪灵根、双/三属性真灵根、天灵根、变异灵根；另有5类启蒙渠道。灵根细目标为可定位第127章的二手整理，发行页只公开开头，不冒充原文终审。境界和资质分别记录，不设置父母修为决定孩子灵根的公式。炼虚、合体、大乘相关身份继续限定在灵界聚落。

诡秘隔离第五纪1349与1358两个背景；增加鲁恩、因蒂斯及相关城市背景，并明确具体街区和家庭组合属于项目改编。当地教会普通雇员与非凡岗位分别记录，教会身份按地区限制，不因某个途径而推定所有人的组织归属。

第60章与第72章正式发行正文支持3个恩赐序列：舞蹈家9、托钵僧侣8、受契之人7。仅在1358背景加入受赐家庭，并以明确的庇护、污染控制条件加入一个猎人特性与舞蹈家恩赐并存的组合。不是任意两种途径随机拼接。

孩子改为“是否具有先天非凡特性尚待确认”；抽到序列6亲代时补充少量特性遗传的可能性和受孕时状态未记录的限制。不将部分特性等同完整序列9，不使用序列平均值、固定继承率或直接继承父母实力。

所有旧有家庭、公开职业、成长倾向与新增条件均标明游戏改编。成长倾向不作婴儿认知诊断，也不能替代灵根、物种特征或非凡能力。家庭资源由基础家庭条件与实际抽到的双亲岗位渠道合并，避免把家族标签等同必然能力。

## 维护结构

| 字段 | 用途 |
| --- | --- |
| settings | 世界背景或时代池，含id、name、description、canon_scope和weight |
| species | 物种池；birth_state、features、life_span描述出生与物种背景；可有lineages祖源池 |
| regions | 地区池；context、species_ids、family_ids限定出生范围 |
| families | 家庭池；parent_profile_ids选择身份，birth_options按出生维度列出允许选项 |
| parent_profiles | 父母身份池；power_set_ids选择力量组合，affiliation与resources描述关系和渠道 |
| powers | 力量定义表；system、rank、path、acquisition区分体系与来源，risk和birth_note说明风险和出生影响 |
| power_sets | 实际抽取的力量组合池；power_ids可含一个或多个已定义力量，notes记录该组合的条件 |
| birth_axes | 每次分别生成的出生维度；label控制显示标题，options为该维度的选项池 |
| traits | 成长倾向池，显示标题由trait_label决定 |
| birth_notes | 全世界通用的出生说明，不包含可执行规则 |

实际抽取池使用有限正数weight；powers和birth_axes只是定义表，不设无效权重。力量概率统一维护在power_sets，避免同一规则出现两个权重来源。每个维度分别归一化，父母独立抽取；权重全部属于游戏设计，不能视为原作人口分布或跨世界强弱排名。

地区、家庭、身份、力量定义及组合可以用setting_ids声明时代范围；家庭、身份、力量定义及组合可用region_ids声明地区范围。未声明表示不额外限制。引用列表保持非空；不以零权重或空列表模拟禁用。

出生维度的家庭限制写在family.birth_options；地区需要额外限制时写region.birth_options，最终取交集。例如技术家庭既可出现在地表也可出现在轨道，但照护渠道由地区进一步限定。选项不接受脚本、表达式、条件语言或可导入函数。

所有世界、池条目、嵌套祖源和出生选项具有provenance、source_refs、source_locator、review_note及reviewed_on。source_summary表示名词或分类有来源，仍须结合来源的访问程度判断证据；mixed表示资料与项目搭配并存；adaptation表示项目设计。不要把游戏岗位组合的来源标成原作规定。

生成顺序为世界→背景时代→地区→同族同祖源→家庭→父母身份与力量组合→出生维度与成长倾向。出生状态归物种保存；结果保存完整快照。新结果使用isekai_v2，图片和文字仍可展示原有isekai_v1快照。

## 后续扩充边界

新增同结构条目可只改JSON；新增世界还需更新world_files。扩充前检查所有引用、时代/地区可用身份和出生选项交集。不要把sources、backlog、revision或verification误加入world_files。

当前仍采用普通同族自然出生。混血、未知双亲、收养、人工生命、特殊神话诞生、西大陆授箓、其他外神完整链及完整遗传公式保留待办；具备原章和关系条件后再设计对应语义。没有把尚未证实的设定自动变成概率规则。

本轮只进行资料结构、Python语法、Ruff与模板语法静态检查，没有编写或执行测试，没有启动机器人。

## 其他资料与离线更新

现实投胎的人口与地图JSON位于上一级daily_reborn目录，同样通过核心JSON工具使用。自定义assets_path时，应将本目录放入相应资源位置。

人口与地图更新脚本在可导入madokabot的项目环境中运行，默认写入项目根目录assets/json/daily_reborn；自定义资源路径使用--data-dir指定其json/daily_reborn子目录。脚本先生成临时文件再替换快照，不回读旧插件数据目录。
