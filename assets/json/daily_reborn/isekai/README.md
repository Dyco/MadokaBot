当前资料版本 `2026.10.19-v6`，结构版本 3。四类世界为奇幻世界、赛博未来、仙侠修仙、诡秘世界。世界 ID、模式名、数据库表名、积分和每日次数规则保持不变。

运行资料通过公共资源管理器定位 `json/daily_reborn/isekai/`，使用核心 `JsonDataStore` 读取。修改资料后重启生效；自定义资源目录也需同步当前文件。旧结构不做兼容或迁移。

| 世界 | 三项人生结果 |
| --- | --- |
| 仙侠修仙 | 玄力、寿命、地位 |

| 诡秘世界 | 财富、寿命、非凡等级 |

综合分为四项递减星级分之和（最高 80）加人生质量分（最高 20），总分为 0～100。修仙综合修为、寿元与地位；诡秘综合财富、寿命与序列；赛博与奇幻综合财富与寿命。婚育只描述人生结果，不因未婚无子扣分。赛博躯体的人类和机械比例合计 100%。

当前结果格式为 `isekai_life_v1`。保留已生成的当前格式快照，重复查看不重新抽取；更早格式只提示重开或次日领取。历史仅展示具备 count/world/gender/score 的条目，缺少字段直接跳过，不补全、不迁移、不删除玩家记录。

## 文件与关联

- `manifest.json`：资料与结构版本、标题、说明、性别权重、世界清单和来源目录文件名。
- 四个世界 JSON：当前抽取使用的地区、物种、家庭、父母身份及力量组合。
- `sources.json`：当前仍被引用的官方、二手及项目来源，保留访问程度、支持内容和证据限制。

| 字段 | 当前用途 |
| --- | --- |
| settings | 世界背景或时代，决定可用地区与身份 |
| species | 父母同族及人物种族的候选池 |
| regions | 通过 species_ids、family_ids 限定地区中的物种和家庭 |
| families | 通过 parent_profile_ids 限定父母身份，rarity 关联家境星级下限 |
| parent_profiles | 父母职业和身份，通过 power_set_ids 指向可用力量组合 |
| powers | 力量名称、体系和参考资料的定义表 |
| power_sets | 实际参与抽取的力量组合，通过 power_ids 关联一项或多项力量 |

实际抽取池均使用有限正数 weight；powers 只是定义表，不带抽取权重。条目可用 setting_ids 和 region_ids 限定时代、地区；未声明即不额外限制。所有关联列表非空，并且必须引用当前世界内的有效条目。不使用零权重模拟禁用，不执行配置中的表达式或脚本。

生成顺序为世界→时代→地区→同族家庭→父母身份与力量→综合人生。父母独立选择适用的身份与组合；地区、家庭及身份关联继续约束抽取。原胎儿面板的出生状态、祖源细分、出生条件、启蒙渠道、资源方向及成长倾向已退出当前格式，不再生成和保存隐藏结果。

## 背景与较低实力规则

奇幻世界以灰鹰的弗拉尼斯为背景，突出剑与魔法、骑士与巨龙。底层职业资料用于约束父母能力范围，界面转换成见习、熟练、资深、大师、传奇等叙事称谓；不将卡片作为 D&D 规则模拟器。现有九类物种的寿命使用玩法预设，不推导混血或神话出生机制。

赛博未来采用原创未来社会，参考资料不代表复刻 2045 或 2077 正史。岗位技能与管理身份不直接等同原作职业能力，义体比例属于游戏设置。

修仙参考《凡人修仙传》的境界名称，保留人界／灵界的身份范围；炼虚、合体、大乘相关身份仍限定于灵界地区。宗门层级、具体职务、寿命及人物修为为游戏模拟，不推导父母修为决定人物灵根的公式。

诡秘保留第五纪 1349 与 1358 两类时代及相应的地区、身份、力量约束。非凡特性与恩赐分别记录；已收录的猎人特性／舞蹈家恩赐组合不推广为任意途径拼接。非凡等级只从当前力量资料抽取，不凭空生成序列名称。

已有父母身份的较低实力档继续保留，不提高原有最高实力：奇幻补原生整数职业等级；赛博补岗位入门及较低熟练度；修仙补适用身份的炼气、筑基；诡秘补同一来源的序列 9、8。不新增境界子等级，不为凑够选项数量破坏身份门槛。较低档、岗位资格和全部权重属于项目设计，不是原著人口统计或现实资格规范。

条目的 source_refs、provenance、source_locator、review_note 等保留证据与改编边界；source_summary 不表示原文已经完整直读。混血、人工生命、西大陆授箓和未核定的外神完整链不在当前抽取范围。

## 静态维护

新增世界需登记 world_files；同结构条目可直接维护各世界 JSON。检查唯一标识、正权重、来源、跨池引用与所有时代／地区的可用家庭和父母身份。仅进行 Python、JSON、模板语法及引用检查，不启动机器人或运行随机模拟。
