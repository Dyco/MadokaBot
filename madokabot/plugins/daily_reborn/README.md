# 每日投胎 · Daily Reborn

只保留两组入口，均遵循全局 `COMMAND_START`。以下示例使用 `/`：

| 模式 | 免费投胎 / 查看当天结果 | 重开（每次 5 积分） |
| --- | --- | --- |
| 世界 | `/reborn`、`/投胎` | `/reborn 重开`、`/投胎 重开` |
| 中国 | `/rebornCN`、`/投胎中国` | `/rebornCN 重开`、`/投胎中国 重开` |

`重开` 也可写作 `reroll`。旧入口 `每日投胎`、`daily_reborn` 已移除。

每位用户按上海时间，世界和中国模式**各自每天免费抽取一次**，跨群、私聊共用各模式的结果，免费投胎无需注册。
重复使用普通投胎命令返回当天结果，数据库联合主键保证并发请求及重启后不会免费重抽。
当天已投胎且已注册的用户可以使用 `/投胎 重开` 或 `/reborn reroll`，每次消耗 5 积分，重新随机出生地、性别与全部属性，并替换当天结果。
重开不限制次数，只要积分足够即可；普通投胎命令随后查看最新结果。扣款与结果保存处于同一事务，积分不足、当天尚未投胎、生成或保存失败时均不扣款。
世界记录表保留 `madoka_daily_reborn_record`，中国记录表为 `madoka_daily_reborn_china_record`，随项目现有数据库初始化流程建表。
必须先领取所选模式当天的免费投胎，才能在该模式重开；两个模式共用账号积分，重开不会影响另一模式的结果。
生成结果成功保存后才返回；图片失败时发送文字结果及扣款提示，之后使用普通投胎命令即可免费重新渲染同一结果。

## 世界人口数据

- 来源：[联合国 World Population Prospects 2024](https://population.un.org/wpp/)，当前快照来自 2025 年更新的官方 `GEN/01/REV1` 工作簿。
- 原始文件：[Demographic Indicators Compact](https://population.un.org/wpp/assets/Excel%20Files/1_Indicator%20(Standard)/EXCEL_FILES/1_General/WPP2024_GEN_F01_DEMOGRAPHIC_INDICATORS_COMPACT.xlsx)。
- 当前使用 2026 年 Medium variant（中方案）预测，共 237 个国家/地区。这是统一口径预测，不是各国当年的已公布实测值。
- 出生地抽样概率 = 当地年度出生人数 / 全球各地区年度出生人数之和。直接使用原表出生人数，单位从千人转换为人；不会将粗出生率直接作为权重。
- 性别抽样使用原表出生性别比：男婴概率 = 性别比 /（性别比 + 100）。
- 中国内地、台湾、香港、澳门保留原始统计分区，以免重复统计，名称统一使用中国内地、中国台湾、中国香港、中国澳门。
- 使用许可：[CC BY 3.0 IGO](https://creativecommons.org/licenses/by/3.0/igo/)。

人口快照不在运行时自动联网更新。年度切换或联合国数据更新后，在项目根目录手动运行：

```powershell
.venv/Scripts/python.exe madokabot/plugins/daily_reborn/update_data.py --year 2027
```

也可用 `--workbook <已下载的xlsx路径>` 和 `--map <已下载的GeoJSON路径>` 复用原始文件。
更新脚本校验完整性后写入 `data/population.json`、`data/world_map.json`；更新完成需重启机器人以刷新内存缓存。
快照与文字结果保留实际使用的数据年份，快照不会随系统年份静默冒充最新数据。

## 中国人口数据与分区地图

中国版覆盖 31 个内地省级地区及中国香港、中国澳门、中国台湾，共 34 项，按各地区出生人数归一化抽样。
快照核对日期为 2026-10-11，主要采用各地 **2025 年官方统计**；来源链接、年份、估算标记和人口输入保存在 [china_population.json](data/china_population.json)。

- 北京、天津、江苏、福建、西藏、青海由官方出生率乘以上年末与当年末常住人口平均值估算出生人数，卡片人数标为“约”。
- 黑龙江暂未取得 2025 年完整官方出生指标，采用[中国统计年鉴 2025 表 2-7](https://www.stats.gov.cn/sj/ndsj/2025/html/C02-07.jpg)中的 **2024 年**出生率与年末人口估算，卡片明确显示 2024 年及“约”。
- 中国香港：2025 年出生 31,100 人，男婴 16,200 人、女婴 14,900 人；[香港政府统计处人口统计表](https://www.censtatd.gov.hk/en/web_table.html?id=115-01011)。原表按百人取整，性别比例使用该精度。
- 中国澳门：2025 年出生 2,870 人，男婴占 51.0%；[统计暨普查局年度人口统计](https://www.gov.mo/zh-hant/news/1221356/)。粗出生率由出生人数除以年末人口近似计算，标为估算。
- 中国台湾：2025 年登记出生 107,812 人，男婴 55,797 人、女婴 52,015 人，包含金门、连江；[官方人口出生统计表](https://gec.ey.gov.tw/File/33FC56963EB27121?A=C)。这里是登记年口径，粗出生率由出生人数与年平均人口估算。
- 内地省级地区未取得同年出生性别比，统一采用[国家卫生健康委公布的 2025 年全国出生性别比 111.5](https://study.bjwomen.gov.cn/thought/politics/2026/08/28/19235.shtml)作为模型参考。这不代表各省实际男女出生比例，也不是总人口性别比；港澳台使用上述当地出生性别数据。

各地公报取整、统计口径及黑龙江年份差异使抽样权重之和不等于单一全国统计数，不对缺项伪造同年实测值。
中国快照单独维护；`update_data.py` 仅更新世界数据。更新中国数据时须同时核对各行出生人数、出生性别比、年份、来源及估算说明，修改后重启机器人刷新缓存。

中国卡片使用 [DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector) 的[省级 GeoJSON](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)，转换为离线 [china_map.json](data/china_map.json) 中的 SVG 路径。
阿尔伯斯等积投影下，34 个省级地区分别绘制，抽中地区使用与世界版一致的浅绿色高亮；台湾可独立高亮，南海诸岛及断续线显示于右下附图，港澳另有局部放大图。
边界保留原始全部顶点，画框裁切配合附图显示；地区定位使用同一数据源的行政中心，旧投胎记录的地区编号可直接用于新地图。
[供应方说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)：数据来自高德开放平台，仅供学习交流。这张游戏示意图不作为自然资源部审定的标准地图，也不沿用旧底图的审图号。

原先[自然资源部标准地图](http://bzdt.ch.mnr.gov.cn/browse.html?picId=4o28b0625501ad13015501ad2bfc0045)的 [china_map.jpg](data/china_map.jpg) 作为完整原图参考保留（GS(2016)1600号），不再用于卡片渲染。
代表点用于指示省级地区，不模拟具体城市或地址。地图可独立更新，不改出生人口数据和已保存的投胎结果：

```powershell
.venv/Scripts/python.exe madokabot/plugins/daily_reborn/update_china_map.py
```

支持 `--map <已下载的GeoJSON路径>`。脚本校验 34 个省级地区、断续线图层和人口数据地区映射后才替换地图；更新后重启机器人刷新缓存。

## 地图与评分

世界地图来自 [Natural Earth 地理单元数据](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_map_units.geojson)，
按经纬度等距投影生成本地 SVG 路径，简化用于娱乐示意，定位点代表地区而非具体出生城市。
台湾、香港、澳门与中国共用高亮编号 `CHN`；抽中中国任一统计分区时都会高亮包含台湾的中国范围。
地图数据为 [Public domain](https://www.naturalearthdata.com/about/terms-of-use/)。

家境、健康、智力、魅力、运气五项属性独立抽取 **1～5 星，每半星一档**，最低保证一星，不按出生地或性别加减星。
每行固定显示五颗五角星，分别用实心、左半实心和空心表示，只保留属性名、星级及稀有度标签。

| 单项星级 | 单次抽取概率 | 展示 |
| --- | --- | --- |
| 1 | 10% | 普通 |
| 1.5 | 16% | 普通 |
| 2 | 24% | 普通 |
| 2.5 | 24% | 普通 |
| 3 | 16% | 优秀、蓝色 |
| 3.5 | 7% | 优秀、蓝色 |
| 4 | 2% | 卓越、紫色辉光及星芒 |
| 4.5 | 0.8% | 史诗、金色闪耀及星芒 |
| 5 | 0.2% | 传说、虹彩星星及渐变描边 |

这些概率针对每一项属性；免费投胎和积分重开使用相同概率。卡片输出为 PNG，辉光、闪耀和星芒采用可保留在静态图片中的效果。
综合评分升级为**人生潜力**，以平均实力为基础，再考虑顶尖天赋、配套属性、多项高星、组合共鸣和均衡基础，满分 100。

| 评分项 | 规则 |
| --- | --- |
| 基础 | 五项平均星级 × 20，四舍五入为整数 |
| 天赋 | 最高项 4 / 4.5 / 5 星时，基础部分分别保底 70 / 82 / 90 分 |
| 支撑 | 有 4 星以上属性时，其余四项总星级超过 4 的部分每满 2 星加 1 分，最多 6 分 |
| 高星 | 每多一项 4 星以上属性加 3 分，最多 12 分 |
| 共鸣 | 指定两项都达到 3.5 星时每组加 3 分，最多 9 分 |
| 均衡 | 五项全部至少 2.5 星加 2 分，全部至少 3 星加 4 分，两档不叠加 |

基础与天赋先取较高值，再加支撑、高星、共鸣、均衡分，最后限制在 100 分以内。85 分及以上 SSR、70 分及以上 SR、50 分及以上 R，其余 N。
因此单项 5 星、其他四项均 1 星仍有 90 分 SSR；提高任一属性不会使综合潜力下降。分数不根据出生地、性别变化，也不另抽一份随机评分。
共鸣组合为家境＋智力、智力＋运气、魅力＋运气、健康＋智力、健康＋运气、家境＋魅力。

卡片右侧只展示分数和评级，与左侧五项属性区域上下对齐。免费投胎和积分重开使用同一套评分规则。
新结果增加 `attribute_system=stars_v1` 标记，`attributes` 仍使用原有五项中文键。
潜力评价使用 `evaluation_system=potential_v1`，结果保存评分及评分明细；已有的人生走向字段不再展示。
旧百分制记录在显示时按“原值 / 20 就近取半星，再限制在 1～5 星”转换；旧百分制及旧星级记录按新规则补全潜力评价，不修改原始记录，不重新抽样，也不额外扣积分或消耗次数。
属性、星级及评级均为游戏设定。
